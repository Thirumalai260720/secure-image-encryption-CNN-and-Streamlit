Secure Image Encryption and Retrieval Framework Using CNNs and Streamlit

📌 Project Overview

The Secure Image Encryption and Retrieval Framework is a cybersecurity and deep learning project designed to provide secure image encryption and retrieval using Convolutional Neural Networks (CNNs) and Streamlit.

The system combines image processing, encryption techniques, and CNN-based feature extraction to create a secure framework for handling image data.

🎯 Objectives

- Secure image data through encryption techniques.
- Use CNNs for image feature extraction and processing.
- Provide an interactive web interface using Streamlit.
- Support secure image retrieval and analysis.
- Evaluate the effectiveness and complexity of the implemented approach.

🛠️ Technologies Used

- Python
- Convolutional Neural Networks (CNN)
- Streamlit
- NumPy
- OpenCV
- Matplotlib
- Image Processing
- Cryptography / Image Encryption

⚙️ Key Features

- 🔐 Image encryption and secure processing
- 🧠 CNN-based feature extraction

- 📊 Histogram analysis
- 📈 Encryption complexity evaluation
- 🌐 Streamlit-based interactive interface

🚀 How to Run

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/secure-image-encryption-CNN-and-Streamlit.git

2. Open the project folder

cd secure-image-encryption-CNN-and-Streamlit

3. Install the required Python libraries

Make sure Python is installed, then install the required dependencies used by the project.

pip install streamlit numpy opencv-python matplotlib

4. Run the Streamlit application

Depending on the application entry point:

streamlit run app.py
